Browser Sessions

Create named browser sessions for manual setup. Each session runs Chrome in a virtual display. Start VNC to connect and configure the browser (login, etc). Sessions can then be used by automated controllers.

Browser Controller

Run an automated browser controller on an existing session. The controller will navigate to the URL and perform automated actions. VNC will be started automatically if not already running.
